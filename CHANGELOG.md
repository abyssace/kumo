# Historial de cambios

## 0.1.0 — 2026-11-01

Primera distribución local de kumo (F1–F6).

- Java 21, cliente Ollama manual y modelos configurables; sin frameworks de IA.
- Indexado TXT/Markdown/PDF con persistencia JSON y citas por página o líneas.
- Preguntas en streaming, resúmenes Stuff/MapReduce y lectura de código sin ejecutarlo.
- Fichas `brief` con plantilla JSON editable y validación de tareas con evidencia.
- Redacción `write` desde el índice con aviso de cobertura parcial y fuentes recuperadas.
- Instaladores por usuario para Windows y Linux, sin instalar Java, Ollama ni modelos.
- Distribución ZIP con dependencias y lanzadores; preservación de configuración e índices.

### Fuera del alcance de esta versión

Chat interactivo, detección incremental de cambios, interfaz web y OCR. El tríptico
académico se prepara al final del proyecto. Ver `README.md` para límites de los modelos
y de la estimación de tokens; el contenido generado siempre debe revisarse.
